A sequence detector is a sequential circuit used to detect a specific pattern of bits in a serial input stream. It continuously monitors the input and generates an output signal whenever the desired sequence is recognized. Sequence detectors are commonly implemented using finite state machines (FSMs) such as Mealy or Moore machines.
