A 4-to-2 Encoder is a combinational circuit that converts one active input out of four input lines into a 2-bit binary code. It has 4 inputs (D0–D3) and 2 outputs (Y1, Y0). The output represents the binary equivalent of the active input line, assuming only one input is high at a time.
