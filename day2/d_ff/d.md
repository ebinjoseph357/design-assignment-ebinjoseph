A D Flip-Flop (Data Flip-Flop) is a sequential circuit used to store one bit of data. On the active edge of the clock signal, the output Q takes the value present at the D (data) input and retains it until the next clock edge. D flip-flops are widely used in registers, counters, and memory circuits.
